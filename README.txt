Himeyuri / HMYR

  一门通用语言：同一份语义，既能当脚本立刻跑，也能拧到硬档进实时音频回调。
  它的主张只有一句——每一个论断都可被检验。

  名字取自卍解所现之力：山丹（ヒメユリ，珊瑚百合）与火。在灰烬里也要开出一朵花。

====================================================================
看板娘
====================================================================

小一孁こはね（おひとめこはね）——乡村出身、憧憬都市的少女，卍解所现之力正是山丹与火，
也就是这门语言名字的来处。她负责门口的招呼，不进制机房：形象卡、职责与界限见 MASCOT.txt（MASCOT.txt）。

开源定位
====================================================================

HMYR 是开源语言：规格与实现统一采用自拟的 CZGD·PL-1.1（LICENSE-CZGD-PL-1.1.txt，权利不限用途与人群、并额外许可同人、二次创作与「改完不回馈」）、符合性套件公开、
提案与决策留痕、兼容性政策公开。三条反面承诺——不做开源皮私有关键、不做规格私有化、不靠不兼容升级收租。

详情见 SPEC.txt（SPEC.txt） 第 8 节。

====================================================================
这份规格怎么写的
====================================================================

沿用 KID 的 DOCTRINE（https://github.com/Nesarf_Mollor/Kohane-Index-Desuno/blob/main/DOCTRINE.txt） 的写法：

  ・每条主张带 [验]：由什么检验（符合性用例 / 编译器自报 / 基准 / 人工评审）
  ・没想清楚的写 [悬]，并且不假装已经想清楚
  ・只在文档里出现、标准库里找不到对应物的「借来」，算装饰，不算集百家之长

====================================================================
里程碑（顺序本身就是设计）
====================================================================

M1 规格草案（本文）→ M2 宿主实现 → M3 符合性套件 → M4 首个真用户（KPB 的谱／混／音色）
→ M5 可嵌入（KID 里跑一段脚本）→ M6 工具链（格式化器、LSP）→ M7 自举

自举是最后一桥：Go、Dart、C# 都借别的语言活了很多年，这不是退让，是活法。

====================================================================
与 KID 的关系
====================================================================

HMYR 不是 KID 的一部分，是它的邻居：KID 认得、索引、验证；HMYR 写出东西。
两者共享同一套脾气（可检验、只增不改、依赖可见、运行时不专属），第一个交点是 KPB。
