A plan file for this repository, read from the milestones the SPEC already states

The project map lives in two halves, and only one of them was here. tools/impact.mjs
answers "which suites does a change touch", and mapagree proves it agrees with
mega-index-map's library_project file by file. What was missing is the goal network:
what is finished, what is open, and what depends on what.

This adds design/PLAN.json for exactly that. It is an index, not a new claim -- every
goal is one of the milestones SPEC.txt section 5 already numbers, or one of the two
models section 6 already declares settled:

  M1 spec, M2 host implementation, M3 conformance and error codes, M4 KPB as the
  first real user, M5 embedding (the only one still open), M6 toolchain, M7
  bootstrap, plus the memory model and the concurrency model.

Eleven entries in total: one project root, nine done, one open. M5 is open rather
than blocked on purpose -- design/RELAY.txt has the subprocess and JSON-RPC design,
and what is missing is the host side of that channel, not the language.

Two corrections while writing it, both found by running the tools rather than by
reading:

The first version listed directories in touches (src/, test/, tools/). library_project
expands those, so host-impl came back with 250 files and toolchain with most of the
repository -- a map whose every goal points at everything answers nothing. They are
concrete files now, and the largest goal names five.

The second: test/plan.test.mjs has a negative section that rewrites one specific
verifiedBy entry ("test/independence.test.mjs") and asserts the check goes red. My
first table did not contain that suite, so the negative test could not run and the
suite failed on its own guard -- "the change did not land, so this section verified
nothing". That guard is right: a negative test that silently skips is worse than no
test. Adding the independence goal (the six measurable properties in
design/INDEPENDENCE.txt, dated 2026-11-04) gave it something to rewrite.

Verified: node test/plan.test.mjs passes 13 of 13, and node tools/check-all.mjs
--only impact,mapagree,plan holds all three (26 + 6 + 13).
